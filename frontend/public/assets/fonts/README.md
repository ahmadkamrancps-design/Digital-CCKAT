# Local Urdu/Arabic font

Noto Naskh Arabic variable font, weights 400–700, copied without modification
from [Google Fonts](https://raw.githubusercontent.com/google/fonts/ad2e6647e3d97ad5a8b6b5f95042f99161af5915/ofl/notonaskharabic/NotoNaskhArabic%5Bwght%5D.ttf),
repository commit `ad2e6647e3d97ad5a8b6b5f95042f99161af5915`. The upstream font family also supports Urdu.

Copyright 2022 The Noto Project Authors. Distributed under the SIL Open Font
License 1.1; see `OFL-NotoNaskhArabic.txt`. The font is served from the application's
own origin so Urdu does not depend on an external font provider or OS font install.
It is used by Urdu question content and the candidate keyboard/readiness guide.

SHA-256: `67b5a525a661b607971fbd3f96a81b89d3a768e74534fca84f18ac97e6fab72f`.
